# Used Car Resale Price Prediction

## Project Description

Used Car Resale Price Prediction is a Machine Learning regression project that predicts the resale price of a used car based on different car features.

The project uses historical used-car data containing information such as brand, model, manufacturing year, kilometers driven, engine capacity, fuel type, transmission, ownership, insurance status, service history, city, and original price.

The dataset was cleaned and preprocessed by handling missing values, correcting data types, and converting categorical features using One-Hot Encoding. Feature engineering was also performed by creating a new feature called Car Age.

A Random Forest Regressor model was trained to predict the resale price of used cars. The model was integrated with a Streamlit web application where users can enter car details and get an estimated resale price.
